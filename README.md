# Давтагддаг үнэгүй тэмцээнд зориулсан арилжааны бот

Тохирсон шаардлагыг 2026-11-04-нд нэгтгэв. Хэрэглэгч Монгол Улсад оршин суудаг гэдгээ баталсан.

## Зорилго

Бот зөвшөөрдөг, давтан үнэгүй оролцдог, нэг тогтсон арилжааны стратегид нийцэх дүрэмтэй демо тэмцээнүүдийг сонгож зэрэг оролцох. Арилжааны өгөгдөлд тулгуурлан ботоо сайжруулах. Тэмцээний шагнал нь бодит зорилго бөгөөд урт хугацааны гол үр дүн нь эрсдэлээ хянаж, шинэ нөхцөлд давтагдах гүйцэтгэл үзүүлдэг систем хөгжүүлэх юм. Бодит мөнгөөр ирээдүйд ашигтай ажиллах боломжийг тусад нь үнэлнэ.

## Тэмцээн сонгох шаардлага

- Эхний нэг, хоёр оролцоогоор хязгаарлахгүй, дараагийн тэмцээнүүдэд мөн үнэгүй оролцох боломжтой байх.
- Депозит болон бодит дансны доод хөрөнгийн шаардлагагүй байх.
- Автомат арилжаа / EA ашиглахыг зөвшөөрсөн байх.
- Монголд оршин суугч оролцох, шагналаа авах эрхтэй байх.
- Өдөр тутмын, долоо хоногийн болон бусад ойрхон давтамжтай тэмцээнүүдийг идэвхтэй хайх; сар тутмын тохирох тэмцээнийг мөн хамруулах.
- Нийцтэй тэмцээнүүдэд зэрэг оролцох; тусгай өөр стратеги шаарддаг эсвэл үйл ажиллагааны хувьд зөрчилтэй тэмцээнийг шүүн хасах/хойшлуулах. Цаг давхцах нь дангаараа хасах шалтгаан биш.
- Нийтлэг орох/гарах дохио, үндсэн параметр болон эрсдэлийн бодлоготой нэг стратеги ашиглах; дансны хэмжээ ба техникийн нөхцөлийг тусад нь тохируулах.
- Бодит мөнгөн шагнал, арилжааны кредит, кредитээс олсон ашгийн татан авалтыг ялгаж бүртгэх. Кредиттэй шагналыг шууд татах мөнгө гэж тооцохгүй.
- Давтамжтай үнэгүй цуврал гэдгийг ирээдүйд нөхцөл нь хэзээ ч өөрчлөгдөхгүй гэсэн баталгаа гэж үзэхгүй. Оролцох бүрдээ хүчинтэй дүрмийг шалгах.

## Ботын үндсэн шаардлага

- Тэмцээн / данс тус бүрийн эхлэх хөрөнгө, хугацаа, цагийн бүс, хэрэгсэл, хөшүүрэг, захиалгын хэмжээ, доод арилжааны тоо, стратегийн хоригийг тусад нь тохируулах.
- Оргил equity-гээс тооцох, эхлэх хөрөнгөөс тооцох, өдрийн болон нээлттэй алдагдлын хязгааруудыг хооронд нь ялгах; нэг томьёог бүх тэмцээнд хэрэглэхгүй.
- Ижил хувь, ижил equity тооцоололтой нөхцөлд нийтлэг trailing drawdown хамгаалалт нь анхны хөрөнгийн тогтмол хязгаарыг мөн хангана. Өөр хувь, daily reset, margin болон бусад ялгааг тусад нь шалгана.
- Нээлттэй ашиг, алдагдал, зардлыг оролцуулан equity болон хасагдах босго хүртэлх зайг данс бүрээр хянах.
- Шинэ захиалгын хэмжээ, нийт нээлттэй эрсдэлийг хязгаарлах; зохион байгуулагчийн босгоос өмнө ажиллах дотоод хамгаалалттай байх. Үнийн огцом өөрчлөлт, гүйцэтгэлийн зөрүүнээс хязгаар давах боломжийг бүрэн арилгасан гэж үзэхгүй.
- Өөр тэмцээнүүдийн дансыг андуурахгүй, данс бүрийн гүйцэтгэл ба хамгаалалтыг тусгаарлах.
- Зэрэг оролцох, олон данс, хуулбар арилжаа, данс хоорондын эсрэг байрлалын хязгаарлалтыг байгууллага бүрээр мөрдөх.
- Дохио, захиалга, гүйцэтгэл, зардал, equity, уналт, алдаа, хамгаалалтын үйлдлийг бүртгэх; нууц үг бүртгэлд хадгалахгүй.
- Стратегийн хувилбар, тохиргоо, өгөгдлийн хугацааг тэмдэглэж, үр дүнг дахин шалгах боломжтой байлгах.

## Хөгжүүлэлт ба үнэлгээ

1. **Судалгаа:** шаардлага хангасан тэмцээнүүд, оролцох эрх, дүрэм болон техникийн холболтыг баталгаажуулах.
2. **Эхний хувилбарын загвар:** нэг энгийн стратеги, данс бүрийн эрсдэлийн хамгаалалт, бүртгэлийн шаардлагыг тодорхойлох. Холбогдох платформууд батлагдсаны дараа хэрэгжүүлэх технологийг сонгох.
3. **Түүхэн туршилт:** хөгжүүлэлтэд ашигласан болон үнэлгээнд хадгалсан хугацааг тусгаарлах; ирээдүйн мэдээлэл ашиглахгүй; спред, шимтгэл, үнийн гүйцэтгэлийн зөрүүг тооцох.
4. **Шинэ демо туршилт:** тохиргоог тогтоож, дараа нь шинээр үүсэх арилжааны үр дүнг хэмжих. Туршилтын явцад өөрчлөлт оруулбал шинэ хувилбар болгон ялгаж бүртгэх.
5. **Зэрэг тэмцээнүүд:** баталгаажсан дүрэмтэй тэмцээнүүдэд тусдаа тохиргоогоор оролцож, туршилтын өгөгдөл болон боломжит шагнал цуглуулах.
6. **Давтан үнэлгээ:** нийт зардлын дараах өгөөж, дээд уналт, хасагдал, гүйцэтгэлийн алдаа болон янз бүрийн зах зээлийн нөхцөлийн үр дүнгээр сайжруулах.

Тэмцээнд түрүүлсэн эсвэл хасагдаагүй үр дүн нь бодит дансанд тогтвортой ашигтай ажиллахыг дангаараа батлахгүй. Бодит дансны арилжаа, төлбөртэй үйлчилгээ энэ ажлын хүрээнд ороогүй. Хэрэглэгчийн хүсэлтээр Oracle Always Free сервер үүсгэж, MT5/EA ажиллах орчныг бодитоор шалгасан.

## Одоогийн төлөв

2026-11-05: локал судалгааны эхний стратеги, зардал/эрсдэлтэй backtest, MT5-ийн read-only түүх экспорт, захиалга өгдөггүй native shadow EA бэлэн. XMGlobal демо данснаас 70,370 EURUSD M15 лаа авч шалгахад тогтмол baseline стратеги үнэлгээний хэсэгт −9.95% өгөөжтэй, 10% дотоод хамгаалалтаар зогссон. Ашигтай бот батлагдаагүй; ML сургалт, demo order executor болон шинэ стратегийн серверийн байршуулалт хийгдээгүй. [Туршилтын тайлан ба ажиллуулах команд](docs/baseline-research.md).

Дараагийн локал хувилбарт 7/14 хоногийн тусдаа данстай давтагдах шат, optional entry-cost filter, тогтсон харьцуулалтын CLI нэмсэн. 28 тест давсан. Хөгжүүлэлтийн өгөгдлийн тусдаа validation дахь 30 долоо хоногийн нэг шатны дундаж өгөөж baseline −1.110%, шүүлтүүртэй −0.331%; хоёул алдагдалтай. Шүүлтүүр одоогоор зөвхөн Python судалгаанд бий; native shadow EA baseline хэвээр. [Давтагдах шатны дэлгэрэнгүй](docs/recurring-rounds.md).

Сүүлийн локал шинэчлэл: бүрэн H1/H4 лааны causal дохио, M15 гүйцэтгэл, calendar carry зардал, 8 тогтсон стратегийн сан/сонголт/validation нэмсэн; 38 тест давсан. H4-ийн min-lot feasibility-г тусдаа1% risk batch-аар шалгахад re-entry calibration net+$12.24/PF1.039 байсан ч validation−$71.02/PF0.612 болж, сонгох шалгуур давсангүй. Ашигтай, deploy-ready бот олдсон гэж үзээгүй. [Стратегийн хайлтын бүх дүн](docs/strategy-discovery.md).

Oracle Always Free E2 Micro серверийн өмнөх MT5 runtime probe хэвээр: XMGlobal демо үнийн холболт, процесс тасрах/сервер дахин асахад сэргэлтийг шалгасан. Сургалт, параметрийн хайлтыг локал компьютер дээр, байнгын ажиллагааг сервер дээр хийнэ. XMTrading-ийн тэмцээний MT5/EA холболтын талаар албан асуулт явуулсан; агуулгын хариу хүлээгдэж байна. Доорх тэмцээнүүд нь судлах нэр дэвшигчид; оролцох/шагнал авах эрхийг бүгдэд нь эцэслэн батлаагүй.
