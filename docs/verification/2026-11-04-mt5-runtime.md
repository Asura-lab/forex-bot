# Oracle E2 Micro дээр MT5 ба EA ажиллуулах бодит шалгалт

Баталгаажуулсан цаг: **2026-11-04 17:37, Улаанбаатар (UTC+8)**.

## Дүгнэлт

**Энэ сервер нэг MT5 терминал болон хөнгөн MQL5 EA ажиллуулж, XM Global демо серверийн бодит tick хүлээн авч чадсан.** Процессыг хүчээр тасалсны дараа болон серверийг бүтнээр нь дахин асаахад үйлчилгээ, демо холболт, EA автоматаар сэргэсэн. Баталгаажуулалтын скриптийн бүх шалгалт амжилттай гарсан.

Стратегийн эцсийн бот хараахан хийгдээгүй. Энэ нь сервер дээрх ажиллагааны туршилт юм; сургалт, параметрийн хайлтыг локал компьютер дээр хийнэ.

## Орчин

- Oracle Always Free `VM.Standard.E2.1.Micro`, Chuncheon.
- Ubuntu 24.04.5 LTS, x86-64; Linux-д харагдсан RAM 952 MiB.
- Wine 11.21 Staging; MT5 x64 build 6295; Xvfb-ийн хувийн дэлгэц, TCP listener-гүй.
- Одоо байгаа диск дээр 2 GiB swap нэмсэн; instance, дискний allocation, төлбөрийн төрлийг өөрчлөөгүй.
- XM Global демо данс, EURUSD/M15. Дансны дугаар, нууц үг тайланд ороогүй.
- `RuntimeProbe` EA: tick тоолох, секундийн таймер, 10,000 давталттай тогтмол математик тооцоолол, CSV heartbeat. Захиалга өгөх кодгүй.
- Автомат арилжаа, DLL импорт хаалттай. Арилжааны захиалга өгөөгүй.

## Нөөцийн хэмжилт

Хостыг хоёр удаа тус бүр ойролцоогоор 3 минут, 5 секундийн зайтай 36 удаа хэмжсэн. Асаалт, холболтын эхний ачаалал багтсан. Санах ойн нэгж MiB.

| Үзүүлэлт | Эхний үе | Сервер дахин ассаны дараа |
| --- | ---: | ---: |
| MT5 RSS дээд хэрэглээ | 316.86 | 246.33 |
| MT5 PSS дээд хэрэглээ | 301.30 | 230.95 |
| Хостын хамгийн бага MemAvailable | 294.63 | 373.52 |
| Нийт хостын swap дээд хэрэглээ | 104.29 | 135.49 |
| Хостын CPU busy дундаж, steal-гүй | 14.68% | 10.87% |
| Хостын CPU steal дундаж | 39.81% | 25.03% |

Swap хэрэглэсэн тул үүнийг swap-гүй туршилт гэж ойлгохгүй. MT5-ийн өөрийн memory үзүүлэлт болон Linux RSS/PSS нь өөр хэмжүүр.

Дахин асалтын дараах EA snapshot: 258 heartbeat, 256.994 секунд, бүх бичлэгт `connected=1`, нийт 544 tick. Таймерын зай дундаж 1,000 ms, p95 1,010 ms, дээд 1,066 ms. Туршилтын тооцооллын p95 265.3 микросекунд. Баталгаажуулах үед сүүлийн heartbeat 0.84 секундийн настай байсан.

## Тохиргоо ба хүрээ

SSH түлхүүрийн хамгаалагдсан хуулбар хэрэглэгчийн `.ssh` хавтаст, демо холболтын нууц мэдээлэл серверийн хувийн хавтас дахь mode 600 файлд байна. Нууц үг, түлхүүрийн агуулга Git болон хэмжилтийн файлд ороогүй.

XM-ийн албан таталтын суулгацын гарын үсэг `Valid`, signer `MetaQuotes Ltd.` байсан. Тус суулгацын серверийн каталогиор ердийн MT5-ийн каталогийг шинэчилсний дараа XM Global холболт амжилттай болсон. `systemd` нь сүлжээ, Xvfb-ийн дараа MT5 эхлүүлж, процесс тасарвал сэргээнэ. Wine-д config замыг Windows backslash хэлбэрээр дамжуулдаг.

Туршилтын EA сервер дээр ажиллаж байна. Бага давтамжтай, хөнгөн EA-ийн эхний хувилбарыг энэ серверт байрлуулах боломж батлагдсан. Хамтын CPU-ийн хүлээлт, асаалтын хугацаа бодитоор ажиглагдсан; сэргэлт агшин зуур болоогүй. Нэг холболтын log-д broker ping ойролцоогоор 208 ms байсан; бүх туршилтын дундаж биш.

Эцсийн стратеги эсвэл сургаж экспортолсон модель бэлэн болмогц яг тэр хувилбарын RAM, inference latency, хамгаалалтыг дахин хэмжинэ. Энэ богино туршилт нь олон хоногийн тасралтгүй ажиллагаа, HFT, захиалгын гүйцэтгэл, ашгийг батлаагүй.
